# Watch an agent's shared browser

Choose **In browser** in a thread's header or sidebar row to watch its shared browser,
including pages running hidden or headless. The live view shows the page title and URL.
Picture-in-picture is available on supported clients.

The view cannot type, click, navigate, resize the agent's page, or take control. Close it
to stop watching without stopping the agent. When the agent closes its page, the stream ends.
Credential entry and pages containing protected fields hide the image rather than exposing
sensitive information.

The integration must be available on the machine running the agent. Existing browser
sessions from before the integration was installed are not shown; the agent's next
shared-browser session can appear without interrupting its current work.
