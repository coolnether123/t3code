# Tell your computers apart

Open Settings > General > Computers. Each connected computer has its own name, color, and Show developer tools switch.

Set a short computer name and pick a color. Move to another control or press Enter to save your edit. These choices are saved on that computer. Your desktop app and phone browser use the same choices when connected to it.

The computer's name and color appear on chat rows, in the New chat picker, in the computer dropdown, and in the open chat's header. All computers combines the chat lists without hiding which computer owns each chat. Choosing a computer in the dropdown limits the list and New chats to that computer.

Developer tools are hidden by default. Turn on Show developer tools to restore Agent activity, the project filter and new-project button, Copy chat, project actions, Open, and Git controls. The switch applies to that computer's chat header. In All computers, sidebar developer controls appear if any listed computer has them enabled. Turning it off hides the controls again without deleting projects or actions.

Clear the name to use the computer's system name. Reset the color to restore its automatic color. Connect to an offline computer before changing its settings. Older servers need an update before these settings can be saved.

On the React Native app, existing computer labels use the saved name. Color badges, identity settings, and simplified controls are available in the web and desktop clients, including Safari on a phone, not in the native app.
